# Telegram LLM Bot

Простой Telegram бот с интеграцией LLM через OpenRouter API.

## Описание

Данный проект представляет собой **production-ready** Telegram бота с интеграцией LLM, разработанного с применением принципа KISS и функционального подхода. В текущей версии (v1.0.0) бот обладает высокой устойчивостью, умеет отвечать на любые вопросы пользователей с помощью искусственного интеллекта, запоминает контекст диалога, адаптирует свое поведение в зависимости от типа разговора и полностью готов к развертыванию в production с Docker.

## Установка и запуск

### Требования
- Python 3.11+
- uv (для управления зависимостями)

### Настройка проекта

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd telegram-llm-bot
```

2. Установите зависимости:
```bash
make install-dev
```

3. Создайте файл `.env` на основе `env.example`:
```bash
cp env.example .env
```

4. Заполните переменные окружения в `.env`:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

### Создание Telegram бота

Следуйте инструкции в [doc/guides/botfather_setup.md](doc/guides/botfather_setup.md) для создания бота через BotFather.

### Запуск

#### Локальный запуск (для разработки)
```bash
make run
```

#### Docker развертывание (Рекомендуется для production)

1. Настройка environment файла:
   ```bash
   cp env.production.template .env.production
   # Отредактируйте .env.production с вашими реальными токенами
   ```

2. Запуск через Docker:
   ```bash
   # Быстрый запуск
   ./scripts/docker-start.sh
   
   # Просмотр логов
   ./scripts/docker-logs.sh
   
   # Остановка
   ./scripts/docker-stop.sh
   
   # Полная пересборка
   ./scripts/docker-rebuild.sh
   ```

3. Проверка статуса:
   ```bash
   docker-compose ps
   docker stats telegram-llm-bot
   ```
